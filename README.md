# Football Hub Bangladesh (FHB) | বাংলাদেশের ডিজিটাল ফুটবল প্ল্যাটফর্ম 🇧🇩⚽

**Football Hub Bangladesh (FHB)** হলো বাংলাদেশের ফুটবল অনুরাগী, দর্শক ও কনটেন্ট ক্রিয়েটরদের জন্য নির্মিত একটি সম্পূর্ণ, প্রাণবন্ত ও আধুনিক ডিজিটাল প্ল্যাটফর্ম। দেশের ফুটবল ঐতিহ্যকে ধারণ করে বাংলাদেশ প্রিমিয়ার লিগ (বিপিএল), জাতীয় দল ও আন্তর্জাতিক ফুটবলের প্রতি মুহূর্তের তথ্য ভক্তদের হাতের মুঠোয় এনে দেয় এই প্ল্যাটফর্ম।

---

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Core Features)

### ১. লাইভ স্কোর, ফিক্সচার, ফলাফল ও লিগ টেবিল (Live Scores & Standings)
- **রিয়েল-টাইম লাইভ ম্যাচ সেন্টার**: বাংলাদেশ প্রিমিয়ার লিগ (BPL), ফিফা বিশ্বকাপ ও এশিয়ান কাপ বাছাইপর্ব, চ্যাম্পিয়ন্স লিগ ও ইংলিশ প্রিমিয়ার লিগ।
- **বল-বাই-বল টাইমলাইন**: গোল (স্কোরার ও অ্যাসিস্ট), হলুদ ও লাল কার্ড, সাবস্টিটিউশন।
- **ম্যাচ পরিসংখ্যান (Stats)**: বল পজেশন (%), মোট শট, অন-টার্গেট শট, কর্নার, ফাউল ও এক্সপেক্টেড গোল (xG)।
- **ইন্টারেক্টিভ ফ্যান পোল**: ম্যাচের বিজয়ী নির্বাচনে দর্শকদের লাইভ ভোট প্রদান ও শতাংশ বিশ্লেষণ।
- **হেড-টু-হেড (H2H) রেকর্ড** এবং লাইভ ফ্যান চ্যাট স্ট্রিম।
- **বিস্তারিত পয়েন্ট টেবিল (Standings)**: গোল ব্যবধান, পয়েন্ট ও সাম্প্রতিক ৫ ম্যাচের ফর্ম (W/D/L) সহ এএফসি ও রেলিগেশন জোন ইন্ডিকেটর।

### ২. ফুটবল সংবাদ, ট্রান্সফার হাব ও নিউজ ম্যানেজমেন্ট সিএমএস (News & Transfers)
- **ক্যাটাগরিভিত্তিক সংবাদ**: বাংলাদেশ ফুটবল (BPL, বাফুফে ও জাতীয় দল), বিশ্ব ফুটবল, টেকটিক্যাল অ্যানালাইসিস।
- **ট্রান্সফার ও দলবদল রাডার**: দেশি-বিদেশি নিশ্চিত চুক্তি ও গুজবের সত্যতা যাচাইয়ের **"নির্ভরযোগ্যতা সূচক (Reliability Score %)"**।
- **ব্রেকিং নিউজ টিকার**: স্ক্রিনের শীর্ষে স্বয়ংক্রিয় স্ক্রলিং ব্রেকিং নিউজ বার।
- **পাঠক এনগেজমেন্ট**: লাইক, সোশ্যাল শেয়ার (WhatsApp/Facebook) ও কমেন্ট সেকশন।

### ৩. টিকটক-স্টাইল ফুটবল শর্টস প্ল্যাটফর্ম (TikTok-Style FHB Shorts)
- **ভার্টিক্যাল ৯:১৬ ফুল-স্ক্রিন ভিডিও ফিড**: মোবাইল ও ডেস্কটপে স্মুথ সোয়াইপ/স্ক্রল নেভিগেশন (Up/Down অ্যারো ও স্ক্রল)।
- **অটোপ্লে ও সাউন্ড কন্ট্রোল**: সাউন্ড অন/অফ, লাইভ হার্ট লাইক অ্যানিমেশন, সাউন্ড ডিস্ক স্পিন।
- **স্লাইড-আপ কমেন্ট ড্রয়ার**: শর্টস চলাকালীন সরাসরি মন্তব্য পড়া ও কমেন্ট যোগ করার সুবিধা।
- **ক্রিয়েটর আপলোড সিস্টেম**: ড্র্যাগ অ্যান্ড ড্রপ বা সরাসরি ভিডিও লিঙ্ক দিয়ে যেকোনো সমর্থক বা ক্রিয়েটর নতুন শর্টস আপলোড করতে পারেন।

### ৪. দল, খেলোয়াড় ও প্রতিযোগিতা পেজ (Teams & Player Profiles)
- **ক্লাব প্রোফাইল**: বসুন্ধরা কিংস, ঢাকা আবাহনী, মোহামেডান স্পোর্টিং ক্লাব, বাংলাদেশ জাতীয় দল—স্টেডিয়াম, দর্শক ধারণক্ষমতা, ট্রফি কেবিনেট ও বর্তমান স্কোয়াড।
- **তারকা খেলোয়াড়দের প্রোফাইল**: অধিনায়ক জামাল ভূঁইয়া, শেখ মোরসালিন, হামজা চৌধুরী, তারেক কাজীদের বায়ো, আন্তর্জাতিক ম্যাচ, গোল, বাজারমূল্য ও ক্যারিয়ার অর্জন।

### ৫. ক্রিয়েটর মনিটাইজেশন ও আর্নিংস ড্যাশবোর্ড (Creator Monetization)
- **ক্রিয়েটর স্টুডিও**: মোট ভিউজ, ওয়াচ টাইম (ঘণ্টা), ফলোয়ার সংখ্যা ও এনগেজমেন্ট অ্যানালিটিক্স।
- **উপার্জন ও পেআউট (bKash / Nagad)**:
  - ভিডিও ও আর্টিকেল থেকে সিপিএম (CPM) ভিত্তিক আয় (BDT ৳ ও USD $ রেট)।
  - বিকাশ, নগদ, রকেট অথবা সরাসরি ব্যাংক ট্রান্সফারে টাকা উত্তোলনের রিকোয়েস্ট সিস্টেম।
  - অতীতের সকল পেমেন্টের ট্রানজ্যাকশন হিস্ট্রি ও স্ট্যাটাস ট্র্যাক।

### ৬. প্রিমিয়াম মেম্বারশিপ ও বিজ্ঞাপন ইন্টিগ্রেশন (Monetization & AdSense)
- **মেম্বারশিপ টিয়ার**:
  - **Fan Pass (ফ্রি)**: লাইভ স্কোর ও সাধারণ অ্যাক্সেস।
  - **FHB Pro Supporter (৳১৯৯/মাস)**: সম্পূর্ণ বিজ্ঞাপনমুক্ত ব্রাউজিং, গোল্ড সাপোর্টার স্টার ব্যাজ, ট্যাকটিক্যাল হিটম্যাপ।
  - **Ultras VIP Lounge (৳৪৯৯/মাস)**: ভিআইপি ব্যাজ, ক্রিয়েটর আয়ে অতিরিক্ত ২০% বোনাস, বিপিএল ম্যাচের টিকিটে অগ্রাধিকার ও কনফেটি অ্যানিমেশন।
- **Google AdSense ইন্টিগ্রেশন**: রেসপনসিভ টপ লিডারবোর্ড, ইন-ফিড নেটিভ স্পনসর ব্যানার ও সাইডবার অ্যাড ইউনিট।

### ৭. সুপার অ্যাডমিন ড্যাশবোর্ড (Complete Admin Control Center)
- **লাইভ স্কোর কন্ট্রোলার**: যেকোনো ম্যাচের স্কোর এক ক্লিকে বাড়ানো/কমানো (+ / -), মিনিট সেট করা ও স্ট্যাটাস (Upcoming -> Live -> Finished) আপডেট।
- **লাইভ ইভেন্ট ট্রিগার**: গোল, হলুদ কার্ড, লাল কার্ড পুশ করা।
- **নিউজ ম্যানেজমেন্ট**: নতুন আর্টিকেল তৈরি, এডিট, ব্রেকিং নিউজ টগল ও ডিলিট।
- **বিজ্ঞাপন ও পেআউট সেটিংস**: গুগল অ্যাডসেন্স অন/অফ এবং ক্রিয়েটরদের বিকাশ পেমেন্ট অনুমোদন।
- **ব্যাকআপ ও রিস্টোর**: এক ক্লিকে সম্পূর্ণ ডেটাবেজ JSON ফরম্যাটে ডাউনলোড ও রিস্টোর।

### ৮. ভাষা নির্বাচন (বাংলা ও English দ্বিভাষিক)
- এক ক্লিকে সম্পূর্ণ প্ল্যাটফর্মের ভাষা বাংলা এবং ইংরেজিতে পরিবর্তন করার সুবিধা।

## 💻 লোকাল মেশিনে চালানোর নির্দেশিকা (How to Run Locally)

### ১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ২. ডেভেলপমেন্ট সার্ভার চালু করুন (Hot Reloading):
```bash
npm run dev
```
ব্রাউজারে খুলুন: `http://localhost:5173`

### ৩. প্রোডাকশন বিল্ড তৈরি করুন:
```bash
npm run build
```

### ৪. ফুল-স্ট্যাক এক্সপ্রেস ব্যাকএন্ড সার্ভার চালু করুন:
```bash
npm run start
```
ব্রাউজারে খুলুন: `http://localhost:5000`

## 🚀 হোস্টিং ও ডেপ্লয়মেন্ট (Hosting & Deployment)

### Vercel-এ ১-ক্লিকে ডেপ্লয়:
1. রিপোজিটরিটি GitHub-এ পুশ করুন।
2. [Vercel](https://vercel.com)-এ নতুন প্রজেক্ট হিসেবে সিলেক্ট করুন।
3. প্রজেক্টের সাথে যুক্ত `vercel.json` স্বয়ংক্রিয়ভাবে বিল্ড ও রুট কনফিগার করে নেবে।

### Netlify-এ ডেপ্লয়:
প্রজেক্টে যুক্ত `netlify.toml` এর মাধ্যমে Netlify তে পুশ করলেই সরাসরি পাবলিশ হয়ে যাবে।

### Docker কন্টেইনারে চালানো:
```bash
docker compose up -d --build
```
সার্ভারটি পোর্ট `5000` এ রানিং থাকবে।
